Welcome to Micro Tasks

Your personal task manager.. In your browser storage.. It doesn't store data beyond your local !

We don't use this to track the projects like Jira.. We use this to track small items which we don't want to forget. Could be chunks of a larger stuff we do.

We have options for

  • Creating a project item [choose "New Project (+)" from menu]
    • Create a card, which is sub-item for the project
    • we can modify a card [ double click | right click -> choose "Edit" & hit Enter ]
    • If we complete any, close a card [ triple click | right click -> choose "Close" ]
    • We can re-open at any time [ right click -> choose "Re-Open" ]
    • A card can be archived too.. for future uses. [ right click -> choose "Archive" ]
    • And of course, we can delete any card [ right click -> choose "Delete" ]
  • Modify project title [ double click | right click -> choose "Edit" & hit Enter ]
  • Archive a project [ right click -> choose "Archive" ]
  • Delete a project [ right click -> choose "Delete" ]
  • At last we can prioritize a project [ right click -> choose "Prioritize" ]

And we have toggle button on menu to show/hide archived cards & projects

How it does stores the data ?

It uses Indexed DB from browser, whenever we make a change, it will automatically store the data and update sync status on the top-right menu.

When the page is refreshed, the data persists.

But when clear cache is done, the data may get lost. We are working on it to make the DB persists.

Kindly make sure to be careful about clearing cache !!
